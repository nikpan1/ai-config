# Extensions and returns

This is synthetic acceptance-test documentation.

A resident can request one extension of seven days. Approval requires that no subsequent reservation conflicts with the extended period. A rejected request leaves the original due date unchanged. Staff may explain the decision but cannot silently replace it with a different extension.

Returned equipment is inspected for completeness and damage. A missing accessory keeps the return open for follow-up. Damage sends the item to maintenance review. These are independent outcomes: a complete but damaged item still requires maintenance review.

The current workshop pilot accepts a tool return at either the main desk or the workshop desk. This pilot is limited to tools. It does not establish return locations for audio equipment.

The 30-day handling period in policy A and the 45-day handling period in policy B below conflict for the same unclaimed-property process. No effective date or precedence rule is supplied. Keep the difference visible; do not invent a policy winner.

Policy A: Unclaimed personal property is held for 30 days after notice.

Policy B: Unclaimed personal property is held for 45 days after notice.
